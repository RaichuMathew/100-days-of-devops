# Day11
## Task

Install and configure Tomcat on App Server 3 (stapp03), change its listening port to 5004, deploy the provided ROOT.war application from the jump host, and verify that the application is accessible via the base URL.

## Purpose

Ensure successful deployment of a Java web application by validating:

Proper Tomcat installation. Correct port configuration and WAR deployment as ROOT context

Application accessibility from the jump host

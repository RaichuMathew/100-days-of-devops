# Day25 Git Merge Branch
## Task

Create a new Git branch datacenter from master in the repository located at /usr/src/kodekloudrepos/blog on the storage server. Copy the existing /tmp/index.html file (available on the storage server) into the repository, add and commit the file in the new branch, then merge the datacenter branch back into master. Finally, push both master and datacenter branches to the origin repository.

## Purpose

Validate Git branching workflow and repository management in a controlled DevOps environment. Ensure proper branch creation from master, file tracking using staging and commit operations, successful merge without conflicts, and synchronization of both branches with the remote origin repository following standard Git version control practices.

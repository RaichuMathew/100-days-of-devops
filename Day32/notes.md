# Day32 :- Git Rebase
## Task:-
Navigate to the repository cloned at /usr/src/kodekloudrepos. Ensure the master branch is up to date with the remote repository. Switch to the feature branch and rebase it onto the master branch so that the feature branch incorporates the latest changes from master without creating a merge commit. Resolve any conflicts if they occur and complete the rebase process. Finally, push the rebased feature branch to the remote repository, using a force push if required.

## Purpose:-
This task integrates the latest changes from the master branch into the feature branch using rebase instead of merge. Rebasing rewrites the feature branch history by placing its commits on top of the updated master branch, maintaining a linear commit history and avoiding merge commits. This preserves all feature branch work while keeping the project history clean and easier to maintain.

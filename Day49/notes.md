# Day 49:- Deploy application with Kubernetes Deployments
## Task:-
On the jump_host, use kubectl to create a Deployment named nginx using the image nginx:latest, explicitly specifying the latest tag. Ensure the Deployment is successfully created and verify that the corresponding Pod(s) are running in the cluster.

## Purpose:-
This task validates the creation of a Kubernetes Deployment for managing application workloads. Using nginx:latest ensures a specific image tag is explicitly defined. A Deployment provides declarative management, enabling scaling, rolling updates, and self-healing capabilities, ensuring consistent and reliable application deployment within the cluster.

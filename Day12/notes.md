# Day12
## Task

Troubleshoot and fix Apache service on stapp01 so that it is reachable on port 3004 from the jump host, without modifying index.html or weakening security.

## Purpose

Validate service availability, port binding, and firewall configuration using standard Linux networking tools (telnet, netstat/ss, curl). Ensure Apache is running, listening on the correct port, and accessible remotely while maintaining existing security controls.

# Day31 :- Git Stash

## Task:-
Navigate to the Git repository located at /usr/src/kodekloudrepos/ecommerce. List the available stashes and identify stash@{1}. Apply the stash with identifier stash@{1} to restore the saved changes into the working directory. Stage the restored changes, commit them with an appropriate message, and push the updated branch to the origin remote repository.

## Purpose:-
This task restores previously stashed in-progress changes back into the working directory so development can continue. Applying a specific stash ensures only the intended saved changes are recovered. Staging and committing records the restored modifications in the repository history, and pushing to origin synchronizes the updates with the remote repository.

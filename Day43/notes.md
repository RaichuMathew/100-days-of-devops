# Day 43:- Docker Port mapping

## Task:-
On Application Server 3, pull the Docker image nginx:alpine-perl from the registry. Create a container named cluster using this image and configure port mapping so that host port 5003 maps to container port 80. Start the container in detached mode and ensure it remains in a running state.

## Purpose:-
This task validates container deployment with custom port mapping. Pulling the required nginx image ensures the correct runtime environment is used. Mapping host port 5003 to container port 80 enables external access to the web service. Keeping the container running confirms successful initialization and service availability for application hosting.

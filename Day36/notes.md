# Day36 :- Deploy nginx container on app server

## Task:-
On Application Server 1, create a Docker container named nginx_1 using the nginx image with the alpine tag. Start the container in detached mode and ensure it is in a running state. Verify the container status to confirm successful deployment.

## Purpose:-
This task validates the ability to deploy and manage containers using Docker. Running the nginx container with the alpine tag ensures a lightweight web server instance is operational. Verifying that the container is in a running state confirms successful container initialization and proper functioning of the Docker runtime environment.

# Day39:- Creating docker image from container
## Task:-
On Application Server 3, create a new Docker image named blog:devops from the running container ubuntu_latest. Ensure the image is successfully created and verify its presence in the local Docker image list.

## Purpose:-
This task captures the current state of a running container by committing it into a new Docker image. Creating the blog:devops image preserves the container’s modifications, enabling reuse, rollback capability, and consistent deployment of the tested changes across environments.

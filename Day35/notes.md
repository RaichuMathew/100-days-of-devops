#Day35 :- Install docker package

## Task:-
Install docker-ce on the target system using the appropriate package manager and configure the official Docker repository if required. Start and enable the Docker service to ensure it runs automatically on system boot. Install Docker Compose and verify both Docker and Docker Compose installations. Initialize Docker by running a test container to confirm the installation is functioning correctly.

## Purpose:-
This task prepares the system for containerization by installing Docker Engine (docker-ce) and Docker Compose, which are required to build, run, and orchestrate containers. Enabling and starting the Docker service ensures container runtime availability. Verifying the installation confirms that the containerization environment is properly initialized and ready for application deployment.

# Day 38 :- Pull Docker Image
## Task:-
On App Server 3, pull the Docker image busybox:musl from the registry. After successfully pulling the image, create a new tag for the same image as busybox:news without altering the original image. Verify that both tags are available locally on the server.

## Purpose:-
This task validates Docker image management by pulling an image from a registry and creating an additional tag for reuse or version control. Retagging allows the same image ID to be referenced under a different name, supporting environment-specific naming conventions or testing workflows without duplicating image data.

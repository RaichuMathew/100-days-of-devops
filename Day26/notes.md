#Day 26 Git Manage Remote

## Task:-
Update the Git repository located at /usr/src/kodekloudrepos/demo by adding a new remote named dev_demo pointing to /opt/xfusioncorp_demo.git. Copy the file /tmp/index.html into the root of the working repository, stage and commit the file to the master branch, and finally push the master branch to the newly added remote.

## Purpose:-
This task ensures the local repository is aligned with the updated Git server configuration. Adding the new remote enables communication with the new bare repository. Copying the file into the working directory allows Git to track the change. Staging and committing records the update in the local repository history. Pushing the master branch synchronizes the committed changes to the new remote repository, ensuring centralized version control consistency.

# Day07
## Task:
Configure password-less SSH access from the jump host so that the thor user can connect to all app servers using their respective sudo users (tony, steve, and banner).

## Purpose:
To validate that the jump host is correctly configured as a secure automation gateway and that SSH key-based authentication is properly set up for non-interactive access. This ensures scheduled scripts running on the jump host can reliably and securely connect to all app servers using controlled sudo users, enabling automated operations, maintenance, and monitoring tasks.

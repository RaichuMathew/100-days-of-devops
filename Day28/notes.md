# Day28 :- Git Cherry Pick

## Task :- 

Navigate to the repository cloned at /usr/src/kodekloudrepos. Identify the commit on the feature branch with the message "Update info.txt" and cherry-pick that specific commit into the master branch. Switch to the master branch, apply the cherry-pick operation, resolve any conflicts if present, and commit the changes. Finally, push the updated master branch to the remote repository.

## Purpose:-
This task selectively integrates a specific commit from the feature branch into the master branch without merging the entire feature branch. Using cherry-pick ensures only the required changes are introduced while preserving the ongoing development work on the feature branch. Pushing the master branch ensures the remote repository reflects the updated production-ready changes.

# Day42 :- Create Docker Network

## Task:-
On App Server 2, create a Docker network named media using the bridge driver. Configure the network with subnet 192.168.30.0/24 and ip-range 192.168.30.0/24. Verify that the network is successfully created with the specified configuration.

## Purpose:-
This task establishes an isolated container networking environment using the bridge driver. Defining a custom subnet and IP range ensures controlled IP allocation and network segmentation for application containers. Proper configuration supports predictable container communication and future service deployments within the defined network boundaries.
